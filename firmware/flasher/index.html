$ settings --backup

      

        
        
        
      

    

    
Save everything set up on the remote to a file on this computer: devices, activities, routines, Home, Wi-Fi and the Home Assistant sign-in. A password encrypts the file (AES-256, in this browser); without one, the Wi-Fi password and the sign-in are left out. Restore puts it back, on this remote or after a clean install. Paired Bluetooth TVs need pairing again on a new board. Wake the remote first.

$ help

    

      The remote isn't in the list
      

        
Wake it up: press any key, then try again. A sleeping remote switches its USB connection off.

        
Try another cable. Many USB-C cables only charge. Then try another USB port, plugged straight into the computer rather than through a hub.

        
On Linux, your user needs to be allowed to use serial ports: run sudo usermod -aG dialout $USER, then log out and in again.

      

    

    

      “Couldn't connect” or “port is busy”
      

        
Only one program can talk to the remote at a time. Disconnect the console on this page, and close other tabs or programs that might have it open (a serial monitor, Arduino, another flasher), then try again.

      

    

    

      The remote doesn't start, or the screen stays dark after an install
      

        
Install again, choosing clean. If the remote isn't in the list any more, start it in download mode, where it always shows up:

        
    
          
  1. Hold the OK key down.
    2. 
          
  2. Through the slot in the back, touch a small flat screwdriver across the two reset pads, then take it away.
    3. 
          
  3. Let go of OK. The screen stays dark: that's expected.
    4. 
          
  4. Press install here. When it's done, unplug the cable and plug it back in, or short the reset pads once more.
    5. 
        

      

    

    

      It stopped halfway
      

        
The remote may not start until it's installed again, but nothing is damaged, and an update keeps your setup. Plug it back in and press install again. If it isn't in the list, use download mode (above).

      

    

    

      Which browsers work?
      

        
Chrome, Edge or another Chromium browser on a computer (Windows, macOS, Linux or ChromeOS). Firefox, Safari and phones can't connect to USB devices from a web page.
